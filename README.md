# Stacked sales-ready working copy

This is the existing Stacked demo split into three files without redesigning it:

- `index.html` — site content and structure
- `styles.css` — visual styling and responsive rules
- `app.js` — navigation, tabs, FAQ, cart and WhatsApp ordering behaviour

## Before using with a real client
Replace the demo business data, WhatsApp number, email, Instagram URL, locations/hours, menu and reviews. Do not present the collection board as live unless it is connected to a real system.

## Phase 1 demo placeholders

The WhatsApp number in `app.js` is intentionally invalid and the action is blocked. Directions, event email, Instagram, and the Truckside credit destination are also intentionally disabled until verified client destinations are supplied. Do not enable any of them with invented details.
